Обновления

Раз в день, чуть после старта, Pragma Chess спрашивает у GitHub номер последней версии — и ничего больше: данные о вас или компьютере не отправляются. Когда вышла более новая, строка состояния на мгновение говорит об этом, а меню «Справка» предлагает Скачать Pragma Chess …, открывая страницу загрузки. Справка ▸ Проверить обновления… спрашивает сразу; Справка ▸ Проверять обновления при запуске выключает ежедневный вопрос.
