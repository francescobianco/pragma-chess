Преобразование файла PGN

Инструменты ▸ Преобразовать ▸ PGN в базу Pragma… делает новую базу из партий файла PGN любого размера: выберите файл PGN и куда идёт база (папка Databases, имя по файлу, если не выберете другое через Обзор…), затем Преобразовать. Файл читается кусками, партии — на всех ядрах компьютера кроме одного; окно говорит, сколько партий вошло и как быстро, и можно продолжать работу.

Файл PGN не меняется, и к нему ничего не подключено: чтобы держать базу и файл PGN в шаге, используйте База данных ▸ Подключить источник… ▸ Файл PGN. Записи файла, не являющиеся партией с ходами, пропускаются, окно говорит сколько. Отмена останавливает и не оставляет базы; по завершении Открыть базу открывает её.
