# The ChatGPT logo

`chatgpt-logo-black.svg` and `chatgpt-logo-white.svg` are OpenAI's own
assets for the "Continue with ChatGPT" sign-in button, as published with
the Sign in with ChatGPT guidelines
(https://developers.openai.com/siwc/ui-ux-guidelines,
https://developers.openai.com/assets/siwc/sign-in-buttons/chatgpt-logo-<colour>.svg).
They are OpenAI's trademark, used unchanged and only to sign in with
ChatGPT; they are not covered by Pragma Chess's license.
