Проекты

Проект — то, на что вы смотрите: база, партия и ход, сторона доски, движок, панели и тренируетесь ли вы. В заголовке — имя: файла или из Файл ▸ Сведения о проекте… — со звёздочкой при несохранённых изменениях и, когда у проекта есть главы, открытая глава (исчезает, когда проект снова без глав): Openings - The Italian - Pragma Chess*.

  • Файл ▸ Новый проект сохраняет то, что видите — базу, движок, панели — и начинает новую пустую партию, белые внизу.
  • Файл ▸ Открыть проект… и Файл ▸ Открыть недавний проект открывают файл .pch. В файловом менеджере у проекта системный значок документа с пешкой; открытие запускает Pragma Chess.
  • Файл ▸ Сохранить проект и Файл ▸ Сохранить проект как… сохраняют.

Сохранять не обязательно: Pragma Chess открывается так, как вы закрыли.

Панели можно менять размером и закрывать; меню Вид (Ходы, Дерево дебютов, Движок, Список партий) показывает их снова, Вид ▸ Сбросить расположение панелей возвращает как у нового проекта.

Файл ▸ Сведения о проекте… показывает файл проекта, имя, описание, автора, контакты и редакцию (по строке, хранятся в проекте), языки и только ли для чтения. Менять их — исключение, не правило: поля открываются заблокированными, кнопка Изменить с замком разблокирует; имя файла там не меняется (Сохранить проект как… делает это). ? в конце каждого поля говорит, для чего оно.

Только чтение в Файл ▸ Сведения о проекте… защищает проект от необдуманных изменений: главы, заголовки, абзацы, комментарии и варианты нельзя менять, и он не сохраняется — доску всё ещё можно изучать, в заголовке (только чтение). Снимите флажок, чтобы менять. Проекты в комплекте Pragma Chess — только для чтения.
