# Logos of the systems

The logos on the download cards of the site, by their makers' colours.

- `macos.svg` (Apple), `debian-ubuntu.svg` (Debian, Ubuntu), `fedora.svg`,
  `android.svg`: the paths of [Simple Icons](https://simpleicons.org) 16.34.0,
  CC0, filled with each brand's colour (Apple's in a silver grey, so it reads on
  the light and the dark page).
- `windows.svg`: the Windows logo, four squares, drawn here (Simple Icons no
  longer carries it).

They are trademarks of their owners, shown to say which systems Pragma Chess
runs on.
